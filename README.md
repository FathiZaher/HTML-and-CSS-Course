# HTML-and-CSS-Course
Welcome to the official repository for **Fathi Zaher**. This repository contains two primary web development projects designed to showcase front-end proficiency.

## 🚀 Projects Included

### 1. Unique Student Portfolio
A custom-built portfolio utilizing advanced HTML and CSS techniques. 
- **Features:**
  - Fixed navigation bar with hover effects.
  - Video background with text overlay (looping, muted, autoplay).
  - CSS image manipulation (Filters, centering, and rounded edges).
  - Interactive image overlay fade effects.
  - A two-column responsive layout and styled data tables.

### 2. Bootstrap Movie Hub
A cinema-themed project focused on the Bootstrap 5.3 framework.
- **Features:**
  - Responsive navigation using Bootstrap classes.
  - Use of **Card Decks** to display movie information for *Kong: Skull Island*, *Ghost in the Shell*, and *Beauty and the Beast*.
  - **Info Pill Badges** for displaying specific showtimes.
  - Anchor-tag "bookmarks" to jump between page sections (About, Showtimes, Deals).

## 🛠️ Built With
- HTML5
- CSS3 (Flexbox, Grid, Filters)
- Bootstrap 5.3
- Mixkit (Stock Video)
